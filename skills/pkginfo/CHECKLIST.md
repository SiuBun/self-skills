# Siubun 包业务检查清单

使用本清单走读每个包。每一项都需要记录：

- 当前分支和 HEAD。
- 活动入口及证据文件。
- 与同系列原包、Lite、Pro、Plus、Chat、U、E 或 VIP 的差异。
- 结论是代码固定行为、服务端配置行为，还是当前布局隐藏。

## 1. 通话前 VIP 门槛

- [ ] 普通外呼前是否检查 VIP。
- [ ] Popular、New、Following 是否分别检查。
- [ ] Profile、相册、消息详情、通话记录是否检查。
- [ ] 随机匹配、继续匹配是否检查。
- [ ] 来电接听、假来电接听、通话后重拨是否检查。
- [ ] `CallManager` 是否存在中央校验，还是仅由页面入口校验。
- [ ] 是否存在可绕过 VIP 的入口。

## 2. Discover 右下角商品入口

- [ ] 入口显示哪类商品：金币、VIP、订阅、badge 5、badge 6。
- [ ] 商品筛选是否依赖 `type`、`badge`、`initialChargeRecommend`、充值状态或 VIP 状态。
- [ ] 点击时是否重新校验相同条件。
- [ ] 是否显示倒计时。
- [ ] 倒计时是注册剩余时间、持久化时限还是固定循环。
- [ ] 倒计时归零后隐藏、移除商品还是重新开始。

## 3. 通话完成后的决策树

- [ ] 免费、付费、虚拟、随机匹配通话是否走不同分支。
- [ ] 是否判断 VIP、金币余额、历史充值和首充商品。
- [ ] 分别可能弹出哪些弹窗，优先顺序是什么。
- [ ] 商品不存在时是否有明确降级行为。
- [ ] 通话评价与 App 评分是否可能同时触发或竞争。
- [ ] 是否跳转随机匹配完成页。

## 4. 商店页和商品弹窗

- [ ] 金币、VIP、订阅是否分页面或统一列表。
- [ ] 商品 ViewType 和卡片样式如何选择。
- [ ] badge 1 到 6 的实际语义。
- [ ] badge 3、5、6 是否有特殊样式或倒计时。
- [ ] 首充、非首充、VIP、非 VIP 的商品筛选。
- [ ] `ONE_TIME`、`SUBSCRIBE`、周期字段如何参与判断。

## 5. Moment

- [ ] 主导航是否有可达的 Moment 页。
- [ ] Profile 是否有 Moment 子页。
- [ ] 是否只是保留类或资源但入口被隐藏。
- [ ] 不同包的 Profile Tab 顺序是否不同。

## 6. Feed

- [ ] 是否存在独立且可达的 Feed 页面。
- [ ] Feed 位于主导航、Moment 子页还是其他入口。
- [ ] 列表形态、分页和卡片内轮播规则。

## 7. VIP 通话折扣价格

- [ ] Profile 是否显示原价、折后价和删除线。
- [ ] 相册页是否显示。
- [ ] Outgoing、Incoming、FakeIncoming 是否显示。
- [ ] VIP 与非 VIP 展示是否不同。
- [ ] 折扣配置来源和计算规则。
- [ ] 数字类型与格式化是否安全。

## 8. 签到

- [ ] Discover、Moment、Mine 是否有入口。
- [ ] 入口是否活动、隐藏或仅保留接口。
- [ ] 签到进度、奖励和弹窗实现是否完整。

## 9. Mine 免打扰

- [ ] Mine 是否显示可操作入口。
- [ ] 状态是否本地持久化。
- [ ] 有效时长和过期算法。
- [ ] 抑制假来电、真实来电还是 IM 通知。
- [ ] 代码存在但布局隐藏时单独标记。

## 10. Discover 国家筛选

- [ ] 按钮或国家 chips 是否显示。
- [ ] 可见条件是否依赖当前 Tab 和国家列表。
- [ ] 点击后是否真正刷新 Popular。
- [ ] 是否影响 New/Following。
- [ ] 是否存在 VIP 拦截。
- [ ] VIP 判断是否只是注释遗留。

## 11. 随机匹配形态

- [ ] 独立页面、主导航 Tab、底部中央按钮、悬浮按钮或 Popular 内嵌条。
- [ ] 匹配中、命中、失败、余额不足的页面流程。
- [ ] 免费次数、余额和 VIP 的判断。
- [ ] 命中后使用普通 Outgoing 还是专用过渡页。

## 12. Discover 子页和列表项

- [ ] 实际挂载哪些 Tab：Popular、New、Following。
- [ ] 源码存在但未挂载的页面单独记录。
- [ ] Popular 是否存在活动轮播。
- [ ] 轮播基础设施存在但数据不足时标记为未生效。
- [ ] Popular 呼叫按钮是否恒定。
- [ ] New/Following 如何在呼叫与消息按钮之间切换。
- [ ] Free 标签的判断条件。

## 13. App 评分弹窗

- [ ] 是否存在远程开关。
- [ ] 首次关注触发条件。
- [ ] 首次付费通话触发条件。
- [ ] 免费虚拟通话和随机概率条件。
- [ ] 是否防止重复展示。
- [ ] 延迟时间及与其他弹窗的竞争。
- [ ] 正向按钮是否调用 Google Play In-App Review。

## 14. 外呼前 5 秒禁止挂断

- [ ] `PREPARING` 时是否禁用挂断按钮。
- [ ] 是否严格延迟 5000 ms 后恢复。
- [ ] 普通 Outgoing 和随机匹配过渡页是否一致。
- [ ] 配置重建或快速状态切换是否可能提前恢复。

## 更新完成条件

- [ ] 所有目标仓库都记录了分支和 HEAD。
- [ ] 14 项均有结论，不能以“与原包相同”掩盖未实际确认。
- [ ] VIP 分支与公共 Main 的边界清楚。
- [ ] 已区分活动代码、注释代码、不可达代码和布局隐藏。
- [ ] 高风险异常进入系列文件的“风险”章节。
- [ ] 更新日期和会话 ID 已写入对应系列文件。
